// AlgoCoach — 个性化刷题教练

以第一性原则设计：一个越用越懂你弱点的算法训练系统，核心是「做题时不让 AI 插手，做题前后让 AI 最大化价值」。

⚠
核心约束（不可妥协）
做题途中：严禁 AI 提示，编辑器只开 Monaco 本地语言辅助。当前不连接外部 LSP；Agent 在进入题目到提交之间完全静默。
做题前 — Prep Mode
  • 知识点讲解 — Remotion 动画视频，agent 主动生成
  • 题型分析 — 自动识别考点（DP/图/滑窗…），关联历史弱点
  • 自由对话 — 可以问任何问题，agent 记录提问模式
  • 个性化推题 — 基于记忆系统，优先推用户薄弱点
做题中 — Focus Mode
  • AI 完全静默 — Agent 不发任何提示
  • 本地语言辅助 — Monaco 语法高亮、括号匹配与本地建议，不调用 AI
  • 隐式计时 — 记录思考时间，用于分析卡点
  • 被动观察 — 记录修改轨迹（不干预，仅分析用）
做题后 — Review Mode
  • 解题动画 — 通过预置 Remotion 组件展示算法思路与复杂度
  • 复盘分析 — 根据判题事实、训练记录与算法方案定位建模和复杂度差距；当前不自动检查源码
  • 记忆更新 — 将本次卡点写入长期记忆，影响下次推题
  • 自由追问 — 可问「为什么这样更优」「变体题怎么做」
AgentScope + ReMe 记忆架构
  • 工作记忆 — 本次会话上下文（当前题目/对话）
  • 情节记忆 — 每题做题记录（时间/卡点/提交次数）
  • 语义记忆 — 知识点掌握图谱（强/弱/待练）
  • 程序记忆 — 用户解题习惯与常见错误模式

// AgentScope + ReMe 记忆系统

五柱架构 (Memory · Skills · Soul · Crons · Self-Improvement) 应用于刷题场景，核心是让 agent 越来越懂用户弱点。

训练记忆 × 刷题
Memory 记忆
工作/情节/语义/程序四类。每道题的做题历史、卡点、耗时、错误类型都持久化
Skills 技能
生成 Remotion 动画、推题策略、复盘分析、题目难度预测等封装为可调用 Tool
Soul 灵魂
用户画像：编程风格偏好、常犯错误、擅长/薄弱题型、目标赛事/岗位
Crons 定时
每日一题提醒、周报生成、间隔复习推送（Spaced Repetition）
Self-Improve
分析「用户做完后 agent 的推题是否有效」，优化推题策略（实验性）
知识图谱 — 语义记忆结构

每次做题后 agent 自动更新节点状态；弱点节点触发主动推送和知识点动画

// Remotion 动画系统

Agent 主动选择预置组件并填入数据，再由服务端渲染、嵌入 Web 播放器。可选的生成式 JSX 路径单独隔离，默认关闭。

触发场景
  • 前置讲解 — Agent 根据题目考点选择预置知识点动画并提供 props
  • 复盘动画 — 可用预置 `SolutionCompare` 对比算法方案；当前不自动读取用户源码生成对比
  • 追问动画 — Agent 可根据对话选择预置算法动画并填入数据
  • 周报动画 — 每周生成个性化进步回顾视频（本周做了哪些题，哪里进步了）
生成流水线
Agent 分析 题目 + 考点 + 用户历史弱点
→
选择组件 Agent 选择预置 composition 并填 props
→
预置渲染 Remotion CLI 渲染；生成式路径默认关闭
→
Web 播放 Remotion Player 嵌入 UI
💡
当前 Agent 只调用预置组件并填入数据与步骤。任意 JSX 走独立 Bubblewrap 沙箱接口，Docker Compose 未开放所需能力时保持关闭。
Remotion 组件库示意
// 预置 Remotion 组件示例 — BFS 树遍历 export const BFSAnimation: React.FC<{ nodes: Node[], edges: Edge[], steps: Step[] }> = ({ nodes, edges, steps }) => { const frame = useCurrentFrame(); const { fps } = useVideoConfig(); const stepIdx = Math.floor(frame / (fps * 0.8)); const visited = steps.slice(0, stepIdx).map(s => s.node); return ( <AbsoluteFill style={{ background: '#0d1117' }}> <TreeGraph nodes={nodes} edges={edges} visited={visited} /> <StepLabel text={steps[stepIdx]?.explain} /> </AbsoluteFill> ); }; // 预置组件库：ArrayViz, TreeGraph, DPTable, // GraphCanvas, TwoPointer, SlidingWindow, ...

// 开发路线图

当前实现覆盖 LeetCode 刷题闭环、训练记忆与 Remotion 动画；平台接入按明确需求再扩展。

1
LeetCode 核心训练闭环（已完成）
  • Cookie 粘贴认证 + LeetCode GraphQL 题目拉取
  • Monaco Editor 嵌入，Focus Mode 完全禁用 AI 侧边栏
  • 做题前/后 Agent 对话（AgentScope + ReMe + Tool Use）
  • 基础记忆系统：每题结果写 SQLite，能推「最近错误题型」
  • Remotion 动画 MVP：BFS、DP、滑窗、双指针与周报动画组件，agent 能生成调用代码
  • Web UI：题目列表 / 编辑器 / 对话三区布局
2
训练记忆与动画（已完成）
  • SQLite 训练记忆、ChromaDB 相似题检索与知识图谱
  • Spaced Repetition 间隔复习推送（Crons 定时）
  • Remotion 动画库扩展到 15 种算法与解法对比组件
  • 间隔复习、周报与推荐效果回测
  • 周报自动生成（动画 + 文字总结）
3
持续迭代（平台扩展尚未接入）
  • 当前仅支持 LeetCode CN
  • 多平台适配不属于当前范围
  • 推荐效果回测已实现，仅输出人工分析结果
  • OI/xCPC 阶段指导与提交后结构化复盘已实现
  • FOCUS 当前只累计用时，尚未记录编辑轨迹
  • 复盘请求不含用户源码，尚未实现个性化代码对比
  • 真实 LeetCode 登录与提交验证按用户要求留待后续
